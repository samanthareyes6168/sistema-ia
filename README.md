# Sistema de IA

Proyecto de práctica para la materia Arquitectura de Sistemas de Inteligencia Artificial.

## Descripción
Este proyecto es un prototipo inicial para simular la estructura de un sistema de Inteligencia Artificial.

## Objetivo
Practicar el control de versiones con Git y GitHub en un entorno de desarrollo de IA.

## Componentes principales
- Modelo.
- Inferencia.
- Configuración.
- Documentación.

## Tecnologías
- Visual Studio Code
- Python
- Git
- GitHub
